# Dataset manager

`discover.py` checks whether the registry's official reference pages respond. It cannot certify legal rights or determine whether a gated download is available.

Before any download, manually review the current dataset licence, research agreement, consent/use limitations, redistribution restrictions and access procedure. Record the outcome in `dataset_registry.json`. Only set `license_review` to `approved` and `access_status` to `granted` after completing those steps.

For direct downloads, record only a URL explicitly supplied by the dataset provider and permitted by its terms. Never put passwords, tokens or signed private URLs into the registry or source control.
